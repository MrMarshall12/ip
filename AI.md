# AI Usage
## Overview
This project was developed with very minimal AI generated code. 
AI was highly used to gather information from online resources, code completion, code refactoring, and GUI arrangement.

## Tools Used
1. Google Gemini: Information gathering from online resources, e.g., Java documentation, and image generation.
2. IntelliJ built-in AI: Code completion and refactoring, GUI arrangement.

## Usage details
### 1. Code completion and refactoring
AI-powered code completion and refactoring were used heavily when writing Storage.java. The code completion worked
accurately only after the file was 50% written. Before that, the suggestions are almost arbitrary. However, the code
refactoring was very effective.

### 2. GUI arrangement
IntelliJ built-in AI was used to arrange the GUI, specifically prompting it to look at the current codebase and suggest
appropriate improvements with respect to padding, font, color, etc. 

### 3. Information gathering
Google Gemini was used to gather relevant information from online resources. This saved a lot of my time from having 
to go through many documentation pages. While gemini is surfing the internet, I can work on other tasks.

### 4. Image generation
Google Gemini was used to generate images to represent the user and the chatbot.
